## 1. HTTP — Hypertext Transfer Protocol

The foundational protocol for transferring data across the Web. It operates on a client-server architecture using text-based request and response messages.

### Key Concepts

* **Request Structure**: Consists of a Method, URL, Protocol Version, Headers, and optional Body.
* **Response Structure**: Consists of a Status Code, Headers, and Body (content).
* **Statelessness**: Every request is independent. The server does not remember previous requests without explicit mechanisms (like cookies or tokens).

### Core Concepts & Headers

* **HTTP Methods**:
* `GET`: Retrieve data (no request body).
* `POST`: Submit new data.
* `PUT`: Replace existing data entirely.
* `PATCH`: Update data partially.
* `DELETE`: Remove data.


* **HTTP Status Codes**:
* `2xx` (Success): `200 OK`, `201 Created`
* `3xx` (Redirection): `301 Moved Permanently`, `302 Found`
* `4xx` (Client Errors): `400 Bad Request`, `401 Unauthorized`, `403 Forbidden`, `404 Not Found`
* `5xx` (Server Errors): `500 Internal Server Error`, `502 Bad Gateway`


* **Important Headers**:
* `Content-Type`: Specifies data format (e.g., `application/json`, `text/html`).
* `Authorization`: Passes credentials (e.g., `Bearer <token>`).
* `User-Agent`: Identifies the client software making the request.

## 2. APIs — Application Programming Interfaces

An API allows two applications to communicate with each other over structured rules. Web APIs most commonly use the **REST** (Representational State Transfer) architectural style.

### Key Concepts

* **Endpoints**: Specific URLs where an API accepts requests (e.g., `[https://api.example.com/v1/users](https://api.example.com/v1/users)`).
* **REST Principles**: Stateless operations, standardized HTTP methods, and representation of resources (usually returned as JSON).
* **Authentication**: Securing endpoints using API Keys, OAuth2, or JWT (JSON Web Tokens).
* **Rate Limiting**: Limits placed by servers on the number of requests a client can make in a given timeframe (often returns `429 Too Many Requests`).

## 3. `JSON` — JavaScript Object Notation

The universal data-interchange format for web APIs. In Python, JSON maps directly to standard data structures like dictionaries and lists.

### Key Concepts

* **Data Types**: Objects (`{}`), Arrays (`[]`), Strings, Numbers, Booleans (`true`/`false`), and `null`.
* **Serialization / Deserialization**: Converting Python objects to JSON strings (dumps) and converting JSON strings back into Python objects (loads).

### Essential `json` Module Methods

* **`json.loads(str)`**: Parses a JSON-formatted string into Python dict/list.
* **`json.dumps(obj)`**: Serializes a Python dict/list into a JSON string (`indent=4` for pretty printing).
* **`json.load(fp)` / `json.dump(obj, fp)**`: Same operations, but directly reading/writing file objects.

```python
import json

data = {"name": "Alice", "active": True, "skills": ["Python", "HTTP"]}

# Serialize Python dict to JSON string
json_str = json.dumps(data, indent=2)

# Deserialize JSON string back to Python dict
parsed_data = json.loads(json_str)
print(parsed_data["skills"][0])  # Output: Python

```

## 4. `requests` — Pythonic HTTP Client

The standard third-party library (`pip install requests`) for making HTTP requests in Python cleanly and reliably.

### Essential Methods & Attributes

* **Request Methods**: `requests.get()`, `requests.post()`, `requests.put()`, `requests.delete()`.
* **Response Object Attributes**:
* `.status_code`: Integer status code (e.g., `200`).
* `.json()`: Automatically parses JSON response body into Python objects.
* `.text`: Raw text payload (HTML, plain text).
* `.content`: Raw binary payload (images, PDFs).
* `.raise_for_status()`: Raises an HTTPError if response status is `4xx` or `5xx`.


* **Common Parameters**:
* `params=`: Query parameters appended to URL (`?key=val`).
* `headers=`: Custom header dictionary.
* `json=`: Python dictionary to automatically serialize and send as JSON body.
* `timeout=`: Seconds to wait for server response before timing out.



```python
import requests

url = "https://jsonplaceholder.typicode.com/posts"
headers = {"User-Agent": "MyPythonApp/1.0"}
payload = {"title": "New Post", "body": "Content", "userId": 1}

# POST request sending JSON payload
response = requests.post(url, json=payload, headers=headers, timeout=5)

if response.status_code == 201:
    data = response.json()
    print(f"Created post ID: {data['id']}")

```

## 5. HTML Basics — Document Structure

HTML (HyperText Markup Language) defines the layout and content structure of web pages. Understanding it is crucial for web scraping.

### Essential Elements & Attributes

* **Tree Structure**: HTML is a nested Document Object Model (DOM) tree with elements inside elements.
* **Key Structural Tags**: `<html>`, `<head>`, `<body>`, `<div>`, `<span>`, `<p>`, `<a>`, `<table>`, `<ul>`/`<li>`.
* **Important Attributes**:
* `id`: Unique identifier for an element on a page (e.g., `<div id="main-header">`).
* `class`: Non-unique classification tag, often shared by multiple elements (e.g., `<a class="nav-link">`).
* `href`: Target URL in anchor `<a>` tags.
* `src`: Asset source path in `<img>` or `<script>` tags.

## 6. `BeautifulSoup` — HTML Parsing & Web Scraping

An element-parsing library (`pip install bs4`) used to extract data out of static HTML and XML files.

### Key Concepts

* **Parser Choice**: Uses parsers like Python's built-in `'html.parser'` or `'lxml'` to turn raw HTML strings into a searchable tree.
* **Navigation vs. Searching**: Access elements directly by tag attributes or search using CSS selectors and filters.

### Most Important Methods

* **`BeautifulSoup(markup, 'html.parser')`**: Initializes parsing tree.
* **`soup.find(name, attrs)`**: Returns the **first** matching element.
* **`soup.find_all(name, attrs)`**: Returns a list of **all** matching elements.
* **`soup.select_one(css_selector)` / `soup.select(css_selector)**`: Searches using CSS selector syntax (e.g., `.class-name`, `#id-name`).
* **Element Attributes**:
* `.text` / `.get_text()`: Extracts inner plain text.
* `element['attribute']` or `.get('attribute')`: Accesses attributes like `href` or `src`.



```python
from bs4 import BeautifulSoup

html_content = """
<div id="products">
    <div class="item">
        <a href="/p1">Laptop</a>
        <span class="price">$999</span>
    </div>
</div>
"""

soup = BeautifulSoup(html_content, 'html.parser')

# Find using class selector
item_name = soup.find('a').text
price = soup.select_one('.price').text

print(f"Product: {item_name} | Price: {price}")

```

## 7. Browser Automation — Selenium vs. Playwright

When websites load content dynamically via JavaScript, traditional HTTP requests and HTML parsing fail because the initial response body is empty. Browser automation controls real headless/headed browser instances.

### Key Distinction

* **Selenium**: The legacy standard. Uses WebDriver protocols to communicate with browsers. Slightly slower, requires explicit wait configurations, but widely supported.
* **Playwright**: Modern standard built by Microsoft. Uses browser debugging protocols directly. Faster, auto-waits for elements to be ready, handles network interception, and natively supports modern web apps.

---

### Selenium Usage

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()

try:
    driver.get("https://example.com")
    
    # Wait up to 10 seconds for element to exist before interacting
    element = WebDriverWait(driver, 10).until(
        EC.presence_of_element_locator((By.TAG_NAME, "h1"))
    )
    print(element.text)
finally:
    driver.quit()

```

---

### Playwright Usage

```python
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    
    page.goto("https://example.com")
    
    # Playwright auto-waits for selectors to load automatically
    title = page.inner_text("h1")
    print(title)
    
    browser.close()

```
